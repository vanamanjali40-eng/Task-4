Task 4: Dashboard Design
Project
Sales & Financial Performance Dashboard using a simple synthetic sales dataset.

Files
sales_financial_dataset.csv — 180 sample order records, ready to import into Power BI or Tableau.
interactive_sales_dashboard.html — interactive browser dashboard with Region, Category and Month filters.
Task_4_Dashboard_Summary.pptx — presentation summary for submission.
power_bi_measures.txt — suggested DAX measures for Power BI.
dashboard_preview.png — static preview image.
Dataset columns
Order_ID, Order_Date, Region, Category, Product, Units_Sold, Unit_Price, Sales, Cost, Profit, Month.

Open the interactive dashboard
Open interactive_sales_dashboard.html in Chrome, Edge or Firefox. Internet access may be required to load the Plotly chart library from its CDN.

Import into Power BI
Open Power BI Desktop.
Select Get Data → Text/CSV.
Choose sales_financial_dataset.csv and click Load.
Create the DAX measures in power_bi_measures.txt.
Add Card visuals, a Line chart, a Donut chart and a Clustered column chart.
Add slicers for Region, Category and Month.
Apply a consistent navy/blue theme and save as a .pbix file.
Important
This is a synthetic educational dataset, not actual business financial data. The HTML dashboard is interactive; the CSV is Power BI/Tableau-ready. A native .pbix or Tableau .twb file must be saved from Power BI Desktop or Tableau on your device.
